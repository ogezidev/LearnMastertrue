# LearnMaster - Landing Page

## 📁 Estrutura do Projeto

```
src/
├── App.jsx
├── App.css
├── assets/
│   └── images/
│       ├── LearnMasterBranca.png          ← Logo do header
│       ├── CardImagemCriancaAprenda.png   ← Imagem do Hero
│       └── DivisaoPessoas.png             ← Imagem da seção Benefícios
└── components/
    ├── Header/
    │   ├── Header.jsx
    │   └── Header.module.css
    ├── HeroSection/
    │   ├── HeroSection.jsx
    │   └── HeroSection.module.css
    ├── InfoSection/
    │   ├── InfoSection.jsx
    │   └── InfoSection.module.css
    └── BenefitsSection/
        ├── BenefitsSection.jsx
        └── BenefitsSection.module.css
```

## ⚠️ Imagens necessárias
Coloque em `src/assets/images/`:
- `LearnMasterBranca.png`
- `CardImagemCriancaAprenda.png`
- `DivisaoPessoas.png`

> Obs: Os nomes dos arquivos não podem ter caracteres especiais (ç, ã etc).
> Renomeie as imagens conforme os nomes acima antes de importar.

## 🚀 Como rodar
```bash
npm install
npm run dev
```
